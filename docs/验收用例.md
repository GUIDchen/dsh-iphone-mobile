# 验收用例

每条用例独立可执行，失败即视为缺陷。

## 通道

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| A1 | 本机 curl -sI http://127.0.0.1:3080 | 返回 200 |
| A2 | 手机蜂窝网络打开 Tailscale 入口 | 正常加载，无证书告警 |
| A3 | 域名接入后手机打开公网入口 | 先跳 Access 验证，通过后进入界面 |

## 体验

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| B1 | Safari 分享 → 添加到主屏幕后启动 | 全屏无地址栏，刘海与手势条不遮挡内容 |
| B2 | 终端页唤起软键盘 | 输入区不被遮挡，Esc/Tab/Ctrl 快捷条可用 |
| B3 | 长按消息文本 | 可复制，无选区错乱 |

## 可靠性

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| C1 | 流式输出中锁屏 60 秒再解锁 | 消息不缺失、不错序、无重复 |
| C2 | 飞行模式 30 秒后恢复 | 数秒内重连，离线草稿保留 |
| C3 | LOSS=3 下持续两分钟 | 重连有界，check-stream 全程通过 |
| C4 | 禁用 UDP 网络下访问 | 可完成一次审批闭环，不假死 |

## 功能

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| D1 | 触发需批准的工具调用并在手机点允许 | 本机真实执行，界面状态同步 |
| D2 | 长回答生成中点击中断 | 立即停止，等价 Ctrl+C |
| D3 | 启动后台任务并观察 | 输出实时滚动，可终止 |
| D4 | 打开文件查看 diff | 改动可辨，可跳转行号 |

## 通知

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| E1 | 待审批时触发 | 手机收到通知，点击直达该会话与工具调用 |
| E2 | 连续触发多条进度通知 | 只保留最新一条，不刷屏 |
| E3 | 制造失效订阅后推送 | 服务端记录并删除该订阅 |
| E4 | 关闭 Tailscale 后触发 | 当前路线下收不到（已知边界）；接入壳 + APNs 后应能收到 |
